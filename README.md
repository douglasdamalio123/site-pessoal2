# Ateliê São José — Santos em Resina

Site estático (HTML, CSS e JavaScript puros, sem build) do Ateliê São José, negócio fictício criado para o curso "IA para Gestores na Prática" (EDUSIA).

## Estrutura

```
index.html       Página principal
css/style.css    Estilos
js/main.js       Menu mobile e acordeão de perguntas frequentes
img/             Logotipo (logo.svg) e fotos ilustrativas
```

## Como visualizar

Basta abrir o arquivo `index.html` no navegador, ou publicar a pasta no GitHub Pages (todos os caminhos são relativos).

## Pendências

- Depoimentos são fictícios, criados para fins de estudo (o Ateliê São José é um negócio fictício do curso EDUSIA).
- As fotos dos 5 produtos (seção "Nossos produtos") são ilustrações de domínio público/licença aberta do Wikimedia Commons, usadas apenas como referência do santo — **substituir pelas fotos reais das peças assim que estiverem disponíveis** (créditos das imagens atuais estão na própria seção do site).
- Dados de contato (WhatsApp, e-mail, site) são fictícios, conforme a ficha do negócio.
- O fechamento `</body>` está limpo para receber futuramente o `chat.js` do assistente de vendas.
